# JuiceBx

JuiceBx is a modern, high‑performance web music player built with vanilla JavaScript, HTML, and CSS. It features:

- **iOS 28 “Siri Orb”** visualizer with liquid‑glass effects.
- **Google Material 3 (M3) expressive visualizers** – ribbons, blobs, Hi‑Fi spectrum, and a vinyl turntable.
- **Full‑bleed, trippy visualizer modes** with instant tap‑to‑morph transitions (no toast pop‑ups).
- **Sacred 999 tribute modal** showcasing a custom 3D thorn‑rose emblem.
- **Pixel‑perfect UI**: library, playlists, search, settings, and a dedicated dedication page.
- **Robust audio engine** supporting playback, shuffle, repeat, speed control, lyrics sync, and offline downloads.
- **Comprehensive test suite** (`full_release_master_test.js`) that validates every feature and guarantees 100 % pass.

The project is ready for production deployment and can be served as a static web app on any hosting platform (Netlify, Vercel, Firebase Hosting, etc.).
